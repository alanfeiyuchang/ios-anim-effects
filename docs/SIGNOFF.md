## Notable fixes

- **Broken pages:** marquee strip blew up the detail layout; bottom sheet was pushed out of the stage; fog wipe rendered banded fog.
- **Bugs:** undo-snackbar ring stopped counting after first use; list↔grid rows overflowed; elastic underline misaligned after language switch;
  cover-flow / wheel-list centred the wrong item; magnifier bulge jumped on release; fog wipe redrew at 60 fps forever.
- **Layout:** ~15 demos collided with the stage's reset button or touched the edges; several previews clipped at 340 pt.
- **Empty stages:** tap-to-start demos (FAB, radial menu, staggered list, spring chain, particles) now show a hint or idle motion.
- **Prompts:** numbers (durations, springs, scales, counts) aligned with the actual implementation in both languages.
- Preview haptics muted centrally; "VISA" wording replaced to avoid a trademark.

## Known limitations / next ideas

- Fling puck: grabbing mid-flight jumps to the projected end point (needs a presentation-value helper).
- Heavy background/shader previews run at full frame rate in the grid; a 30 fps cap for thumbnails would save GPU.
- Liquid Glass effects need iOS 26 to show real glass; older systems see the material fallback.
- Motion is verified by code review + still frames; feel on a physical device (haptics, 120 Hz) is not yet validated.
- Ideas: Reduce Motion variants, a prompt-vs-defaults lint, code export per effect.
